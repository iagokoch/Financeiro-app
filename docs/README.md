# Project Documentation

This folder contains the technical and planning documentation for the financeiro-app project.

The goal of this documentation is to keep track of the MVP decisions, main user flows, initial date model, and diagrams used to guide development.

## Files

- `mvp-flow.md`
  Describes the main user flow for the MVP.

- `mvp-data-model.md`
  Describes the main entities of the system and their relationship.

- `diagrams/`
  Contains the diagrams created with Excalidraw.

## Current Scope

The MVP will be manual and will not include real bank integrations.

In this phase, the user will abe to:

- create an account;
- create categories;
- create transiotions;
- view a basic dashboard.

Bank integrations through Open Finance or third-party aggregators will be planned for a future phase.
